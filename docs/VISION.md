# VISION

## 为什么做

笔记工具记的是**知识**，不记**人**。录音、健康、天气散落在四五个应用里。AI 没有持久记忆，每次对话都要重新交代一遍「我是谁、我在做什么、我最近怎么样」。

于是每年年底回看，能翻到的只有一堆笔记和截图，看不到这一年的自己怎么过来的。

PKBrain 要把这件事反过来：**按「人的维度」记录，自动沉淀，让 AI 记得你。**

一句话：别人记录你的屏幕，PKBrain 记录你的生活与内心。

## 记录什么

按 [PKBS 最小子集](PKBS-MIN.md)（当前占位版）的 7 维框架：身体、情绪、事业、关系、探索、财富、精神，加一条基线，加时间与目标两条贯穿维。

M0 先落地 4 个维度。够用来验证闭环，不必一次到位。

## 三条不做的边界

1. **不做笔记应用**。知识管理有 Obsidian、Logseq，PKBrain 不做第二个。它管的是「人」，不是「知识点」。
2. **不做云服务**。没有服务端，没有账号，没有同步。数据是本地文件，能导出，能进 Git，能自己备份。
3. **不绑模型**。抽取和提问用哪个模型是可换的：本地 Ollama 与云端 API 走同一条接口。M0 更彻底——规则抽取，一个模型都不需要。

## 产品原则

- **本地优先**：默认不出网。要出网的动作（调云端模型、拉天气）单独开关。
- **只增不改**：记录写下去就不动。修订产生新版本，不覆盖旧的。
- **原始材料不丢**：抽不出结构化字段的正文原样保留。今天的模型抽不出来，不证明明天的抽不出来。
- **可迁移**：Markdown + SQLite 都是能打开的格式。离开 PKBrain 不该有任何损失。
- **隐私分级先行**：从第一条记录起就带 `privacy`，加密可以晚做，分级不能补。

## 怎么验证

作者本人是第一个用户。连续 14 天跑通「每晚对话 → 当日快照」，再开放给早期用户。没跑满 14 天之前，不接受「这个产品有用」这个结论。
