# ADR-0003：开源协议

- 状态：提议，待确认（决策点 D2）
- 日期：2026-10-16

## 背景

产品的价值主张里有两条互相拉扯：

- 数据主权与可迁移——希望别人拿去用、集成进自己的工具链；
- 不做云服务——没有服务端收入，也不靠闭源授权。

## 决定

**Apache-2.0**（待确认后落实 `LICENSE` 文件）。

与 Mem0 一致。宽松，允许集成与商用，生态兼容摩擦最小。

## 后果

好处：

- 别人可以把 PKBrain 嵌进自己的产品，便于形成生态。
- 企业用户法务上无负担，自托管推广更顺。

代价：

- 有人可以拿去做闭源商用，不回馈。
- 社区期待的是「数据在我手里」而不是「代码不许闭源」，这与宽松协议的取向一致，但会损失一部分 AGPL 支持者。

## 备选方案

| 方案 | 取舍 |
|---|---|
| AGPL-3.0 | 与 Khoj 一致。防止闭源商用，但会挡住一部分集成场景 |
| MIT | 更宽松，但缺少专利授权条款 |
| 先不开源（源码可见） | 与 build in public 的定位直接冲突 |
